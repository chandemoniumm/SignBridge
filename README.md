# SignBridge

SignBridge is an application designed for Indian Sign Language (ISL) data collection, model training, and live sign language prediction using a user-friendly GUI.

## Usage Instructions

### Step 1: Data Collection  
Run the GUI application for data collection of sign language gestures.

```bash
# Launch the GUI to collect data 
```

### Step 2: Model Training  
Train the sign language recognition model manually by running the training script.

```bash
python3 train_model_script.py
```

### Step 3: Live Prediction  
Run the GUI again, this time for live sign language prediction.

```bash
python3 gui.py
```

## Features
- Easy-to-use GUI for data collection and live prediction
- Separate training script for flexibility
- Supports Indian Sign Language gesture recognition

## Installation  
Make sure you have Python 3 and required dependencies installed. You may install dependencies via:

```bash
pip install -r requirements.txt````
